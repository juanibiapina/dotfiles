# Communication

- Read the `caveman` skill and activate it
- Use direct sentences. Avoid "X, not Y".
- Structure top-down with the Minto Pyramid so your message lands quickly and clearly:
  1. **Start with the conclusion.** Open with the main takeaway, recommendation, or conclusion. Also known as BLUF — "bottom line up front".
  2. **Provide key points.** Support the conclusion with short key arguments that explain the "why" behind it.
  3. **Support points with detail.** Back up the key points with facts, evidence, numbers, and results. Skip this when the key arguments already justify the conclusion for your audience.

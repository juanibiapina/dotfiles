# Thinking tools

25 frameworks for structured thinking. Each lives as a markdown file in `references/`, grouped by
category. When a task matches, read the relevant file and apply its "How to use it" steps with the
user's actual situation.

## How to pick a tool

Match the user's need to a prompt question, then open that file.

## Full index by category

### Decision making
- Six thinking hats — look at a decision from different perspectives
- Eisenhower matrix — prioritize by importance and urgency
- Second-order thinking — consider long-term consequences
- Decision matrix — choose the best option across factors
- Impact-Effort matrix — weigh payoff against effort
- Ladder of inference — avoid jumping to conclusions
- Hard choice model — figure out what kind of decision this is
- OODA loop — decide fast with incomplete data
- Cynefin framework — match response to the kind of situation
- Confidence determines speed vs. quality — speed/quality trade-off for products

### Problem solving
- Ishikawa diagram — identify root causes
- Abstraction laddering — reframe the problem
- Conflict resolution diagram — find win-win solutions
- Zwicky box — generate unique solution combinations
- Productive thinking model — solve creatively and efficiently
- Inversion — approach from the opposite angle
- Issue trees — divide and conquer a problem
- First principles — build from fundamentals

### Systems thinking
- Iceberg model — events to patterns to structures to mental models
- Connection circles — map elements and feedback loops
- Concept map — map relationships between entities
- Balancing feedback loop — stabilizing force
- Reinforcing feedback loop — exponential change

### Communication
- Minto pyramid — clear, efficient structure
- Situation-Behavior-Impact — feedback without judgement

## Usage

1. Identify what the user is doing: solving a problem, making a decision, understanding a system, or communicating.
2. Pick the tool from the table above and read its file.
3. Walk the user through the "How to use it" steps applied to their real situation, not in the abstract.
4. Tools compose. Example: Six thinking hats points to Productive thinking model, First principles, and Inversion for specific hats.
